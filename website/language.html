Language

Comments are // to end of line. Semicolons are required after statements.

Falsey: nil, false, 0, 0.0, "", [], {}. Everything else is truthy.

Operators

Arithmetic + - * / % (int/int stays int; mix with float yields float). + also concatenates strings. Comparisons == != < <= > >=, unary - !.

Control flow

if (cond) { ... } else { ... }
when (cond) { ... }
while (cond) { ... }
loop (cond) { ... }
for (let i = 0; i < 10; i = i + 1) { ... }
for (x in xs) { ... }
out(expr);
ret expr;

Structs

struct Point { x; y; }
let p = Point { x: 1, y: 2 };
out(p.x);
p.y = 3;

Imports

Compile-time linking. No runtime import opcode.

import util;
import "lib/util.my";
import math;

Resolution checks importer dir, lib/, packages/, builtins/, cwd, parent walks for builtins/, then $MYC_HOME/builtins/. Imported fns become module.fn. Circular imports fail at compile time.

Example

fn fib(n) {
  when (n < 2) { ret n; }
  ret fib(n - 1) + fib(n - 2);
}
out(fib(10));
