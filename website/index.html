myc

Small C11 language with a stack-based bytecode VM. Source files use the .my extension. Pipeline: lex, parse (AST), compile (bytecode), run (call-frame VM).

Values: nil, bool, int, float, string, list, map, struct, function. Control flow: if/while/for (aliases when/loop), compile-time imports, and a builtins/ stdlib.

Build and run

make
./myc examples/fib.my

Also: ./myc -d examples/hello.my (disassemble then run), make test.

Exit codes: 0 ok, 65 parse/compile error, 70 runtime error.

  • C11 compiler (cc)
  • POSIX (sockets, fork/pipe for os.capture)
  • macOS AppKit only for graphics (stub elsewhere)
