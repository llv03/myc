math

import math;
out(math.sqrt(9));
out(math.pi());

Also: e, abs, min, max, clamp, floor, ceil, round, pow, sin, cos, tan, hypot, lerp. sqrt(x) returns nil if x < 0.

fs

import fs;
fs.write("notes.txt", "hello");
out(fs.read("notes.txt"));
fs.remove("notes.txt");

Paths are relative to the process cwd. Cap 8 MiB for reads.

os

import os;
out(os.args());
let r = os.capture("echo hi");
out(r["out"]);
out(os.getenv("HOME"));
out(os.cwd());

Pass only trusted strings to system/capture (shell injection risk).

net / http

import net;
let s = net.listen(8080);
let c = net.accept(s);
net.send(c, "hi");
net.close(c);
import http;
http.serve(8765, handler);
http.serve_routes(8765, {"/": "<h1>hi</h1>"});

Also: mk_response, text, html, json, parse_request, serve_text. Blocking sockets. HTTP/1.1 only.

json / csv

import json;
let s = json.stringify({"a": 1});
let v = json.parse(s);
import csv;
let rows = csv.parse("a,b\n1,2\n");
csv.write("out.csv", rows);

JSON is a practical subset (no 1e3 exponents). CSV is RFC4180-ish with quoted fields.

graphics

import graphics;
if (graphics.available()) {
  graphics.open(640, 480, "myc");
  graphics.text(24, 40, "Hello");
  graphics.run();
}

macOS AppKit only. Colors are floats in 0..1. Text origin is top-left. See docs/graphics.md.
